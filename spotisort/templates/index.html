How it works

Spotify's clients can show a playlist in date-added order, but some — the Tesla player, most car head units — always play it in stored order. The usual fix is to delete every track and re-add it in order, which resets every Date added to today and destroys the thing you were sorting by.

spoti-sort instead computes the shortest sequence of single-track moves that brings the stored order in line with the date order, and applies them one by one. Tracks are never removed, so timestamps, play counts and the playlist's identity all survive. A playlist that's already sorted costs one read and zero writes; one that gained three tracks overnight costs three moves, not a rebuild.

Each playlist is sorted independently with the order you picked for it, so a running mix can stay oldest-first while your main playlist stays newest-first.

Duplicated tracks, local files and podcast episodes are handled by position rather than by track id, so they no longer confuse the sort.
